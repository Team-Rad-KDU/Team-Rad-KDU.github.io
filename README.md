# Team Rad KDU – organisation website

Root site for the **Team-Rad-KDU** GitHub organisation (Society of Radiography and Radiotherapy, KDU).

> **Important:** GitHub only publishes this as `https://team-rad-kdu.github.io/` when the repository is named exactly
> **`team-rad-kdu.github.io`** (matching the organisation name). Rename it in *Settings → General → Repository name*
> if it still has the old `team-red-kdu.github.io` name.

It also hosts the files that only work at a domain root and therefore cover the SIHINA site at `/Sihina/` too:
`robots.txt` (lists both sitemaps), `sitemap.xml`, `llms.txt` and `404.html`.
